# Credits and third-party media

SkyCircuit uses procedural/vector visuals and synthesized gameplay effects wherever practical. The current beta intentionally includes one external media dependency: the background music loop below.

## Background music

- File: `assets/audio/duru-arcade-vibe.mp3`
- Track: `duru-arcade-vibe`
- Author/project: DURU / `uncle-sheepsky/duru-cc0-bgm`
- Source: <https://github.com/uncle-sheepsky/duru-cc0-bgm>
- License: **CC0 1.0 Universal / public-domain dedication**
- Usage: shared gameplay BGM for Android/web and native iOS.
- Playback: approximately `1.08x` baseline, increasing up to approximately `1.16x` during higher combo/ignition energy.

## SkyCircuit-generated effects

The following remain generated by SkyCircuit code rather than bundled third-party samples:

- Tile/placement interaction cues.
- Ignition progression tones.
- Rocket launch effects.
- Firework crack/boom/sparkle effects.
- Procedural/vector gameplay visuals and UI effects.

## Asset policy

Any future third-party image, audio, font, animation, or other media must have its provenance and license documented here before merge.

This file documents third-party media licensing only. The repository currently does not declare a project-wide source-code license; see `README.md` for the source licensing note.
